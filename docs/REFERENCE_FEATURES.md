# BuyJudge 참고 기능 백로그

사용자가 공유한 주식매매 프로그램 강의 예시를 BuyJudge 개발 기준에 맞춰 선별한 목록이다.

## 바로 반영할 기능

### 1. 종목 상세 검색
- 종목코드 또는 이름 입력
- 현재가, 등락률, 고가, 저가, 거래량, 거래대금 표시
- BuyJudge 판정 결과와 연결
- 후보가 아니더라도 개별 종목 확인 가능

### 2. 종합 리포트
- 현재 분석 결과 요약
- 매수후보, 눌림대기, 관망, 위험차단, 통계부족 개수
- 전략 분류별 요약
- CSV 다운로드

### 3. 랭킹 화면
- 거래대금 증가율 상위
- 상승률 상위
- 거래량 증가 상위
- BuyJudge 점수 상위
- 유사사례 상방 상위

### 4. 매매 일지 자동 기록
- 후보 발생일
- 당시 판정
- 현재가, 손절가, 목표가
- 5일, 20일, 60일 이후 결과 추적
- 실제 매매 전 가상매매 검증용

### 5. 안전장치
- 최대 동시 보유 후보 수 제한
- 동일 테마 과집중 경고
- 위험차단 종목 매수 금지
- 통계부족 종목 경고
- 손절폭 과대 종목 제외

## 중기 반영 기능

### 1. 자연어 명령
예시:
- 반도체 후보만 보여줘
- 눌림대기만 보여줘
- 거래대금 많이 붙은 종목 보여줘
- 장기 베이스 돌파형 후보 찾아줘

초기에는 완전한 AI가 아니라 필터 버튼과 텍스트 검색으로 구현한다.

### 2. 예약 실행
- 장 시작 전 1회
- 장 마감 후 1회
- 주말 리포트 1회

초기에는 Streamlit 버튼 실행을 유지하고, 이후 GitHub Actions 또는 서버 스케줄러로 확장한다.

### 3. 텔레그램 알림
- 매수후보 발생
- 눌림가 근접
- 위험차단 전환
- 관심 종목 판정 변화

## 나중에 반영할 기능

### 1. 증권사 API 연동
- 실제 계좌 조회
- 미체결 주문 조회
- 주문 취소
- 체결 알림
- 보유 종목 리포트

조건: 가상매매 기록으로 로직 검증 후 진행한다.

### 2. 스마트 주문
- 금액 단위 매수
- 호가 틱 조절 주문
- 분할 매수 주문
- 전량 매도
- 미체결 일괄 취소

조건: 증권사 API 안정화 이후 진행한다.

### 3. 자동매매 엔진
- 스탑로스
- 트레일링 스탑
- 이동평균선 교차 매매
- 조건검색식 연동
- 돌파매수, 분할 트레이딩, 그리드 트레이딩

조건: 분석기와 가상매매 성과가 충분히 검증된 뒤에만 검토한다.

### 4. 로그인/토큰/보안 관리
- 실제 계좌와 연동할 때 필요
- 지금 단계에서는 불필요

## 적용하지 않을 기능

### 1. 무작정 자동주문
BuyJudge의 현재 목표는 주문기가 아니라 판단 보조기다. 자동주문은 마지막 단계다.

### 2. 급등주 추격 전용 기능
초단기 급등주 추격보다 단기 스윙, 중기 성장 스윙, 장기 베이스 돌파를 우선한다.

### 3. 뉴스만 보고 매수하는 기능
뉴스는 보조 점수로만 사용한다. 차트, 거래대금, 유사사례, 리스크 기준을 통과해야 한다.
